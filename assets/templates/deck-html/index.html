Open Design Slim

Portable prototype handoff

A compact deck scaffold for explaining a design decision, workflow, or implementation plan without any daemon or web runtime dependency.

Why this matters

Remote agents need explicit artifact contracts.

Inputs

User brief, host repository context, and bundled design guidance.

Outputs

Ordinary files: HTML, React, DESIGN.md, tokens, and handoff notes.

Boundary

No runtime API, artifact database, provider proxy, or desktop preview.
