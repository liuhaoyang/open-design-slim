# Visual Checklist

Use this before handoff. Browser or screenshot validation is preferred when the
host supports it; otherwise report that the checks were manual/source-only.

## Layout

- The first viewport communicates the artifact's product or topic immediately.
- Navigation, toolbar, filters, and primary content align to a clear grid.
- Repeated items share stable dimensions.
- No text overlaps or escapes buttons, cards, panels, tables, or slides.
- Mobile layout is not just a squeezed desktop.

## Visual System

- Color roles are semantic and balanced.
- Accent color is used intentionally, not everywhere.
- Typography scale matches the surface: compact inside tools, larger only for
  true heroes or deck titles.
- Borders, shadows, radius, and dividers follow one coherent system.
- Icons, if used, support actions or scanability.

## Interaction

- Hover, focus, active, selected, disabled, loading, and error states are visible
  where expected.
- Controls do not jump in size when state changes.
- Destructive or irreversible actions have a confirmation or clear affordance.
- Forms show labels, validation, and completion feedback.

## Responsive

- Check 390x844, 768x1024, 1280x720, and 1440x900 when practical.
- Decks fit within one viewport.
- Tables or dense panels have a deliberate responsive strategy.
- Touch targets remain usable on mobile.

## Finish

- No placeholder boilerplate remains.
- No generic "AI SaaS" visual tropes dominate.
- Sample data is realistic and labeled when invented.
- The handoff names visual checks that were performed and gaps that remain.
